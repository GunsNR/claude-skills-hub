# SmartOS folder

This is the only folder Smart OS writes into. Subfolders are created
automatically as needed:

- `Daily Logs/` — appended timeline of what happened each day
- `Delegation/` — generated task briefs for Dilshan
- `Research/` — auto-research briefs

Treat anything here as system-generated. Move or copy notes out into the
rest of the vault when you want to keep and edit them.
